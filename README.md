# Software FJ

Proyecto desarrollado para la Fase 4 del curso de Programación.

El sistema permite gestionar clientes, servicios y reservas utilizando programación orientada a objetos y manejo de excepciones en Python.

## Servicios

- Reserva de salas
- Alquiler de equipos
- Asesorías especializadas

## Conceptos aplicados

- Abstracción
- Encapsulación
- Herencia
- Polimorfismo
- Excepciones personalizadas
- Manejo de errores
- Registro de eventos
- Listas de objetos

## Archivos principales

- entidad.py
- cliente.py
- servicio.py
- reserva_sala.py
- alquiler_equipo.py
- asesoria_especializada.py
- reserva.py
- sistema.py
- excepciones.py
- logger.py
- main.py

## Ejecución

Para ejecutar el programa principal:

py main.py

Para ejecutar las pruebas:

py prueba_cliente.py

py prueba_servicios.py

py prueba_reservas.py

## Registro de eventos

Los eventos y errores se guardan en:

registro_eventos.log
